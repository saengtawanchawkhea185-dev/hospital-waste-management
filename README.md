# ระบบบริหารจัดการมูลฝอยอัจฉริยะ (SPA) - MOPH Green Hospital
**โรงพยาบาล ๕๐ พรรษา มหาวชิราลงกรณ**

ระบบเว็บแอปพลิเคชัน Single Page Application (SPA) ธีมดาร์กโหมด (Dark Theme) สำหรับบริหารจัดการ ติดตาม บันทึก และวิเคราะห์ข้อมูลมูลฝอยโรงพยาบาลและเครือข่าย รพ.สต. แบบเรียลไทม์ พร้อมระบบประเมินการลดก๊าซเรือนกระจกและคาร์บอนเครดิตตามมาตรฐานกระทรวงสาธารณสุข (GREEN & CLEAN Hospital) และ อบก. (TGO)

---

## 🚀 ฟีเจอร์หลัก (Key Features)

### 1. แถบเครื่องมือค้นหาและปฏิบัติการข้อมูล (Search & Action Toolbar)
- **การจัดวางปุ่มปฏิบัติการ (Action Buttons Layout):**
  - 🔄 **รีเฟรชข้อมูล** (Refresh latest data)
  - 👁️ **ดูตัวอย่าง (พรีวิว)** (Preview filtered records modal)
  - 📊 **Excel** (Export .xlsx)
  - 🖨️ **พิมพ์ / PDF** (Print view & PDF download)
  - 📄 **CSV** (Export .csv UTF-8 BOM) *(แสดงในหน้าตารางข้อมูล)*
  - 📥 **นำเข้าข้อมูล Excel / CSV** *(แสดงด้านหลัง และซ่อนในหน้าแดชบอร์ด)*
  - 📥 **ดาวน์โหลดแม่แบบ (.xlsx)** *(แสดงด้านหลัง และซ่อนในหน้าแดชบอร์ด)*
- **ตัวกรองและช่องค้นหา (7 ช่อง Multi-condition):**
  - ค้นหาทั่วไป (Instant Keyword Search)
  - ประเภทรายงาน / ชนิดมูลฝอย
  - แผนก / หน่วยงาน
  - วันที่เริ่มต้น
  - วันที่สิ้นสุด
  - **ปี พ.ศ. (Dynamic Buddhist Era Years):** เริ่มต้นครอบคลุมช่วง พ.ศ. 2565 - 2585, สามารถกดปุ่ม `[+ เพิ่มปี]` เพื่อเพิ่มปี พ.ศ. ใหม่ได้ไม่จำกัด พร้อมรันปี พ.ศ. ปัจจุบันตามปฏิทินจริงอัตโนมัติ
  - เดือน (มกราคม - ธันวาคม, ทุกเดือน)

### 2. แดชบอร์ดมาตรฐาน GREEN & CLEAN Hospital กระทรวงสาธารณสุข
- **4 Hero Executive KPI Cards:**
  - 🌟 **ปริมาณมูลฝอยรวมทุกประเภท (Total Waste Generated):** สรุปยอดรวม กก. และอัตราการนำกลับมาใช้ประโยชน์ (Diversion Rate %)
  - 🌿 **คาร์บอนเครดิตสะสม (Total GHG Offset / Carbon Credit):** แสดงค่าเป็นตันคาร์บอนไดออกไซด์เทียบเท่า (`tCO₂e`) และ `kgCO₂e`
  - ☣️ **มูลฝอยติดเชื้อรวมทั้งหมด:** รพ.หลัก + เครือข่าย 21 รพ.สต. (กก.) ควบคุมมาตรฐาน 100%
  - 💰 **มูลค่าการกำจัดรวม:** คิดเป็นบาท (9.75 บ./กก.)
- **ระบบวิเคราะห์การลดก๊าซเรือนกระจกและคาร์บอนเครดิต (TGO Standard):**
  - 🌳 **เทียบเท่าการปลูกต้นไม้ (Tree Equivalent):** คำนวณตามอัตราดูดซับ 10 kgCO₂e/ต้น/ปี
  - ⚡ **เทียบเท่าการประหยัดกระแสไฟฟ้า (Electricity Saved):** คำนวณเป็น kWh
  - 🚗 **เทียบเท่าการลดระยะทางขับรถยนต์ (Vehicle Km Avoided):** คำนวณเป็น กม.
  - ♻️ **ปริมาณขยะอินทรีย์นำไปหมักทำปุ๋ย (Organic Composting):** คำนวณลดก๊าซมีเทนจากการฝังกลบ (0.53 kgCO₂e/กก.)
- **กราฟแนวโน้มคาร์บอน (Carbon Trend Analytics):**
  - 📈 กราฟเส้นแนวโน้มการลดก๊าซเรือนกระจกจริงรายเดือน เปรียบเทียบกับเป้าหมาย MOPH Green Hospital
  - 🍩 กราฟ Donut สัดส่วนแหล่งที่มาของการลดคาร์บอน (หมักปุ๋ยอินทรีย์, คัดแยกขยะทั่วไป, จัดการขยะติดเชื้อ)
- **การจัดกลุ่มมูลฝอย 3 หมวดหมู่ตามเกณฑ์ สธ.:**
  - **หมวด 1:** มูลฝอยทั่วไป & มูลฝอยอินทรีย์/เศษอาหาร
  - **หมวด 2:** มูลฝอยติดเชื้อ (มีคม, ไม่มีคม, รพ.สต. 21 แห่ง, ส่งบริษัทกำจัด)
  - **หมวด 3:** มูลฝอยอันตราย (สารเคมี, ยา/เวชภัณฑ์, ครัวเรือนส่ง อบจ., กัมมันตรังสี)
- **4 แผนภูมิวิเคราะห์ภาพรวม:**
  - สัดส่วนมูลฝอยทุกชนิดของโรงพยาบาล (%)
  - สัดส่วนมูลฝอยอันตราย 4 ประเภท (%)
  - ปริมาณมูลฝอยติดเชื้อ รพ.สต. 21 แห่ง (Rainbow Bar Chart)
  - สถิติมูลฝอยทั่วไปและอินทรีย์แยกตามแผนก รพ. (Horizontal Bar Chart)

### 3. จัดการข้อมูลอ้างอิงและน้ำหนักถัง (Master Reference Data)
- **อ้างอิงถังขยะ (`ref_bins`):** จัดการรหัสถัง และน้ำหนักถังสำหรับหักน้ำหนักสุทธิ พร้อมปุ่ม `[+ เพิ่มใหม่]`, `[📥 นำเข้า]`, `[📄 แม่แบบ]`
- **อ้างอิงแผนก/หน่วยงาน (`ref_departments`):** จัดการรายชื่อแผนกและหน่วยงานในโรงพยาบาล พร้อมปุ่ม `[+ เพิ่มใหม่]`, `[📥 นำเข้า]`, `[📄 แม่แบบ]`
- **อ้างอิงบริษัทกำจัด (`ref_companies`):** จัดการรายชื่อผู้รับกำจัดมูลฝอยติดเชื้อ พร้อมปุ่ม `[+ เพิ่มใหม่]`, `[📥 นำเข้า]`, `[📄 แม่แบบ]`

### 4. สำรองข้อมูล / กู้คืนข้อมูล (Backup & Restore)
- **📥 สำรองข้อมูล (Export / Backup):**
  - **สำรองทุกตาราง (Excel):** สร้างไฟล์ `.xlsx` รวม 8 ตารางหลักใน 1 ไฟล์ (`general_waste`, `infectious_subdistricts`, `infectious_disposal`, `infectious_disposal_history`, `infectious_hazardous_waste`, `ref_bins`, `ref_departments`, `ref_companies`)
  - **สำรองทุกตาราง (CSV):** ส่งออกไฟล์ `.csv` แยกตารางพร้อมกัน รองรับ UTF-8 BOM ภาษาไทย 100%
  - **สำรองโค้ดระบบ (HTML):** ดาวน์โหลดไฟล์ `index.html` ฉบับสมบูรณ์ที่กำลังทำงานอยู่
- **📤 กู้คืนข้อมูล (Import / Restore):**
  - กู้คืนข้อมูลทั้งหมดจากไฟล์ Excel `.xlsx` ที่สำรองไว้ เข้าสู่ฐานข้อมูล Supabase หรือระบบ Sandbox
  - กล่องคำเตือนและหน้าต่างยืนยันความปลอดภัยก่อนเขียนทับข้อมูล
- **🕒 ประวัติการสำรองข้อมูล (Backup History Log):**
  - บันทึกประวัติการสำรอง/กู้คืน วันเวลา, ประเภท, ชื่อไฟล์, จำนวนรายการ, และสถานะ

### 5. บันทึกและประวัติการส่งกำจัดขยะติดเชื้อ (Infectious Disposal & History)
โครงสร้างตารางมีความสัมพันธ์กันแบบ 1-to-Many โดยอ้างอิงผ่าน **`เลขที่การมารับขยะติดเชื้อ` (`disposal_no`)**:
- **1. ตารางบันทึกข้อมูลขยะติดเชื้อบริษัทรับไปกำจัด (`infectious_disposal` - รายถัง):**
  - คอลัมน์ (11 คอลัมน์): `รหัส` (`id`), `วันที่` (`created_date`), `เลขที่การมารับขยะติดเชื้อ` (`disposal_no`), `ข้อมูลถัง` (`bin_name`), `น้ำหนักที่ชั่งได้` (`scale_weight`), `หักน้ำหนักถัง` (`bin_weight`), `น้ำหนักมูลฝอยติดเชื้อรวม` (`net_weight`), `คิดเป็นมูลค่าการกำจัด` (`disposal_cost`), `บริษัทที่มารับไปกำจัด` (`company_name`), `ลงชื่อผู้ส่ง` (`sender_name`), `ลงชื่อผู้บันทึก` (`recorded_by`)
- **2. ตารางประวัติบันทึกข้อมูลขยะติดเชื้อบริษัทรับไปกำจัด (`infectious_disposal_history` - สรุปรวมรายบิล):**
  - คอลัมน์ (14 คอลัมน์): `รหัส` (`id`), `วันที่` (`created_date`), `เลขที่การมารับขยะติดเชื้อ` (`disposal_no`), `รวมน้ำหนักที่ชั่งได้` (`total_scale_weight`), `รวมหักน้ำหนักถัง` (`total_bin_weight`), `น้ำหนักมูลฝอยติดเชื้อรวม` (`total_net_weight`), `คิดเป็นมูลค่าการกำจัด` (`total_cost`), `บริษัทที่มารับไปกำจัด` (`company_name`), `ลงชื่อผู้ส่ง` (`sender_name`), `ลงชื่อผู้บันทึก` (`recorded_by`), `รูปภาพประกอบ1` (`photo_url_1`), `รูปภาพประกอบ2` (`photo_url_2`), `ลิงค์ข้อมูลการชั่งน้ำหนัก (ตช.สำหรับ รพ.)` (`weighing_link`), `เวลาบันทึก` (`created_at`)
- **ความสัมพันธ์และการเชื่อมโยง (Relational Feature):**
  - สามารถคลิกที่ `เลขที่การมารับขยะติดเชื้อ` หรือปุ่ม `[🔍 ดูรายละเอียดรายถัง]` ในหน้าประวัติสรุปบิล เพื่อเปิด Modal Popup สรุปรายการถังย่อยทั้งหมดที่เชื่อมโยงกัน พร้อมยอดรวมและรูปภาพประกอบได้ทันที

### 6. ระบบนำเข้า-ส่งออกและกู้คืนข้อมูลอัจฉริยะ (100% Robust CSV & Excel Engine)
- **Universal Data Normalizer:**
  - แปลงและทำความสะอาดตัวเลข (Number Sanitization): กำจัดเครื่องหมายจุลภาคคั่นหลักพัน (`,`), สัญลักษณ์สกุลเงิน (`฿`, `บาท`), หน่วยวัด (`กก.`) อัตโนมัติ ป้องกันปัญหา `ERROR: 22P02: invalid input syntax for type numeric: "5,642.00"`
  - แปลงวันที่และเวลาสากล (Date/Time Sanitization): รองรับรูปแบบวันที่ไทย (`18/5/2026, 21:45:40`, `01/01/2566`), รูปแบบสากล (`YYYY-MM-DD`, `ISO 8601`), ปี พ.ศ./ค.ศ., และ Excel Serial Date Numbers (`44928`) ป้องกันปัญหา `ERROR: 22008: date/time field value out of range`
  - รองรับชื่อหัวตารางทั้งภาษาไทยและภาษาอังกฤษ (Multi-Alias Header Mapping): จับคู่คอลัมน์ภาษาไทยจากไฟล์งานจริงและชื่อคอลัมน์มาตรฐานของฐานข้อมูล 100%
  - กรองเฉพาะคอลัมน์ที่ตรงตาม Schema ของแต่ละตารางก่อนส่งเข้า Supabase REST API ป้องกันข้อผิดพลาด Unknown Column
- **ระบบแบ่งก้อนข้อมูลขนาดใหญ่ (Batch Chunking - 500 แถว/รอบ):**
  - รองรับไฟล์ข้อมูลขนาดใหญ่หลายหมื่นแถว (เช่น 7,836 แถว) โดยแบ่งส่งรอบละ 500 รายการ พร้อมแถบ Progress Bar แจ้งสถานะแบบเรียลไทม์ ป้องกันปัญหา Request Timeout หรือ Payload Too Large
- **ความเข้ากันได้ 100% กับ Supabase Dashboard Import:**
  - ไฟล์ `.xlsx` และ `.csv` ที่ Export จากระบบจะจัดเก็บตัวเลขเป็น Pure Numeric (ไม่มีจุลภาค) และวันที่ในรูปแบบ ISO ทำให้สามารถนำไป Import ตรงในหน้าเว็บ Supabase Dashboard ได้อย่างสมบูรณ์แบบโดยไม่มี Error
